银河系模型与轨道积分 · Galaxy Model & Orbits

旋臂 / 棒 / 核球（科学参数化粒子仿真）

  • 4 条主臂（Scutum-Centaurus、Sagittarius-Carina、Perseus、Norma-Outer）+ Outer 臂 + 本地臂（猎户支臂）
  • 对数螺旋模型，螺距角 8–16°（Reid 2019 / Vallée 2017）
  • 中心棒：半长 5 kpc、偏 28°（Wegg 2015）+ 花生状核球
  • 太阳位于本地臂（Orion Spur）
R(β) = R_ref · exp( −(β − β_ref) · tan ψ )

轨道积分（135 条平滑轨道）

  • 引力势 MWPotential2014（Hernquist 核球 + Miyamoto-Nagai 盘 + NFW 晕）
  • 数值标定 vc(R☉) = 238 km/s；自实现 IAU 1958 银道变换
  • scipy DOP853（8 阶 Runge-Kutta）反推 3 Gyr，rtol=1e-7
  • 输出 R_peri / R_apo / 偏心率 / z_max / 顺逆行

Reproduce

如何复现 · Reproduce

# 克隆仓库
git clone git@github.com:jianxing-chen/globular-cluster-atlas.git
cd globular-cluster-atlas

# 直接打开 3D 应用（零安装）
open viz/index.html        # macOS
# start viz\index.html   # Windows
# xdg-open viz/index.html# Linux
# 复现数据流水线（可选）
cd scripts
python3 download_catalogs.py   # 1 VizieR 下载
python3 parse_and_validate.py  # 2 解析+校验
python3 build_master.py        # 3 合并主星表
python3 integrate_orbits.py    # 4 轨道积分
python3 process_streams.py     # 5 恒星流
python3 make_figures.py        # 6 静态图
python3 export_viz_data.py     # 7 打包 Web 数据
依赖：numpy · pandas · matplotlib · scipy（轨道/绘图全自实现，无需 astropy/galpy）
